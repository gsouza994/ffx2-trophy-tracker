# FFX-2 HD Remaster Trophy Tracker

A fan-made checklist app to help players track missable trophies, chapter-specific requirements, bestiary completion, and multi-step tasks in **Final Fantasy X-2 HD Remaster**.

## Important: Use alongside a 100% story walkthrough

This tracker is designed to complement a walkthrough that covers **100% story completion**. It is not intended to replace a full story walkthrough, as its primary focus is trophy requirements, missable opportunities, and tracking progress toward the Platinum trophy.

## Requirements

- Windows
- Python 3
- Tkinter available in your Python installation

No third-party Python packages are required.

## How to run

1. Download the `.pyw` file from the latest release.
2. Make sure Python 3 is installed.
3. Open the `.pyw` file with Python.
4. Keep the tracker and its progress JSON file in the same folder to preserve saved progress.

If double-clicking does not open the app, check that `.pyw` files are associated with Python, or try launching it from a Python installation that includes Tkinter.

This is an unofficial, fan-made project and is not affiliated with or endorsed by Square Enix. Trophy requirements and checklist entries may need corrections; feedback and suggestions are welcome.
